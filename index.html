評分方法怎麼算的？

籌碼動能分數

取近10個交易日「外資買超合計＋投信買超合計」占股本比例的平均值（先收斂到 ±3% 避免極端值失真），加上近5日外資、投信買超天數的一致性，兩者以 7:3 混合。單一法人10日內買賣超超過股本8%時，會標記為波動極端並打折計分。

獲利成長分數

以 (2026年預估EPS − 2025年全年EPS) ÷ max(|2025年EPS|, 1) 計算成長幅度，分母下限設為 1，避免 EPS 基期過小時百分比失真，成長區間收斂在 −100%～+200%。若2025年EPS本身接近零或虧損，成長分數封頂65分，避免轉虧為盈的小型股單靠基期效應就拿滿分。

估值分數

本益比在目前篩選出的名單中由低到高排名（愈低分數愈高，佔六成），加上股價距52週高點的空間（愈遠離高點分數愈高，佔四成）。

綜合評分 = 三項分數依你設定的權重加權平均，滿分100。所有排名與估值分數都是在「目前篩選條件」下的相對比較，不是與全市場比較。

資料怎麼更新？

一套排程機器人會在每個交易日收盤後，自動向台灣證券交易所（TWSE）與證券櫃買中心（TPEx）的公開資料 API 抓取最新收盤價（每日「收盤」價，不是即時盤中價）、以及近10個交易日三大法人（外資／投信／自營商）買賣超，重新計算後自動發布到這個網址，不需要你手動操作。

股本與毛利率不在每日自動範圍內，但已於 2026/08/06 對照 TWSE／TPEx 官方公開資料（上市公司基本資料、上市櫃公司綜合損益表，115年第1季，即目前公開資料中最新一季）重新核對更新；毛利率為該季單季營業毛利／營業收入，不是全年數字。

EPS 預估（尤其是 2026 年全年預估）沒有免費的官方數據來源可以驗證或更新——那是分析師對還沒發生的季度的預測，官方公開資料只會在每季財報公布後才更新「實際」EPS。最早的27檔觀察股沿用你朋友原本提供的2026年預估數字（與官方已公布的115年第1季實際數字核對一致）；2026/08/06 新加入的12檔股票（廣達、緯創、智邦、欣興、國巨、聯電、聯發科、長榮、萬海、華航、長榮航空、川湖）的2024/2025年EPS取自 Wantgoo 等財經資料站的年度財報整理，2026年預估取自 FactSet 分析師共識調查（經 Anue鉅亨網轉載），部分個股（如欣興、國巨、長榮、川湖）不同來源之間預估差異較大，請視為粗略參考；萬海目前找不到可靠的2026年共識預估，暫以2025年實際EPS代入計算本益比，成長率不適用，網站上會特別標示。2026/08/06 又加入的4檔（奇鋐、宏達電、聯合再生、中鋼）同樣以財經資料站數字為主：宏達電、聯合再生同樣找不到可靠2026年預估（暫以2025年實際值代入，已標示）；中鋼2026年預估在不同來源間也有分歧（FactSet約0.14元 vs 部分法人估0.42元，暫採FactSet數字，本益比看起來偏高是因為EPS基期極小，非真的估值過熱）；聯合再生2025年毛利率為負值（核心太陽能本業仍虧損）。52週高點對所有新加入的股票都是以加入當天的收盤價為起點，之後只會隨創新高往上調整。如果你有更新的財報或預估數字，隨時可以給我，我會重新整理。

股價與籌碼資料來自台灣證券交易所、證券櫃買中心公開資料 API 每日自動更新（收盤價，非即時報價）；股本與毛利率於 2026/08/06 對照官方最新一季財報核對；EPS預估沿用原始資料或分析師共識調查（詳見上方「資料怎麼更新」說明），實際交易前請以官方即時報價與財報為準。 綜合評分僅為依籌碼、成長、估值三個可得指標所做的量化排序方法，用途是縮小觀察範圍，並不構成個股買賣建議，也不構成任何投資邀約。 本工具不是持牌投資顧問服務，實際投資決策請自行評估風險承受度，或諮詢合格理財顧問。
