評分方法怎麼算的？

籌碼動能分數

取近10個交易日「外資買超合計＋投信買超合計」占股本比例的平均值（先收斂到 ±3% 避免極端值失真），加上近5日外資、投信買超天數的一致性，兩者以 7:3 混合。單一法人10日內買賣超超過股本8%時，會標記為波動極端並打折計分。

獲利成長分數

以 (2026年預估EPS − 2025年全年EPS) ÷ max(|2025年EPS|, 1) 計算成長幅度，分母下限設為 1，避免 EPS 基期過小時百分比失真，成長區間收斂在 −100%～+200%。若2025年EPS本身接近零或虧損，成長分數封頂65分，避免轉虧為盈的小型股單靠基期效應就拿滿分。

估值分數

本益比在目前篩選出的名單中由低到高排名（愈低分數愈高，佔六成），加上股價距52週高點的空間（愈遠離高點分數愈高，佔四成）。

綜合評分 = 三項分數依你設定的權重加權平均，滿分100。所有排名與估值分數都是在「目前篩選條件」下的相對比較，不是與全市場比較。

資料怎麼更新？

每天自動更新：週一到週五台北時間約 16:23 與 18:47，由 GitHub 排程自動向證交所（TWSE）與櫃買中心（TPEx）公開資料抓取：當日收盤價（非盤中即時價）、近10個交易日三大法人買賣超，以及官方最新一季財報的股本、毛利率、累計EPS。財報季別會隨公司公布自動往前（目前為「26年上半年(至Q2)」＝2026年1～6月累計；公布第三季後會自動變成「26年前三季(至Q3)」。毛利率與EPS都是年初累計到該季，不是單季）。GitHub 排程偶爾會延遲數十分鐘。

不會每天自動更新：「2026年全年EPS預估」是分析師對尚未發生季度的預測，沒有免費官方來源，需人工重查。最近一次核對日期顯示在頁面右上角；有取得共識的個股已更新，來源（如 FactSet 中位數、家數、日期）寫在各股展開後的「2026預估來源」。找不到可靠共識的個股，沿用前一版預估或以2025年實際值代入，並以紅色標籤標示。不同來源的預估常有明顯分歧，請視為粗略參考。

52週高點：以加入追蹤當天的收盤價為起點，之後只會隨創新高往上調整，不會回溯抓一整年歷史股價，因此可能偏離真正的52週高點。

股價、籌碼與財報數字來自台灣證券交易所、證券櫃買中心公開資料 API 每日自動更新；2026年全年EPS預估取自分析師共識或前一版整理，實際交易前請以官方即時報價與財報為準。 綜合評分僅為依籌碼、成長、估值三個可得指標所做的量化排序方法，用途是縮小觀察範圍，並不構成個股買賣建議，也不構成任何投資邀約。 本工具不是持牌投資顧問服務，實際投資決策請自行評估風險承受度，或諮詢合格理財顧問。
